## Deskripsi : Ini Adalah penginstalan blackarch linux full 23GB untuk ke penyimpanan
                    internal anda, meskipun anda bisa live booting blackarch ini di usb
                    tapi anda juga bisa menginstallnya di penyimpanan internal anda dengan
                    mudah, dan berikut langkahnya beserta error fix gpg.

                    Minimum Requirements:
                    RAM 2GB, Paling lancar 4GB-8GB
                    Storage Minimal 70 GB (Hanya untuk sistem) Rekomendasi 130GB
                    CPU minimum x86_64 - dan semua komputer sekarang mendukung ini

                        itu bertindak sebagai penengah, jadi jika kalian hanya mengisinya dengan *.iso saja, itu tidak akan terbaca

## Langkah 9.------------------ INI YANG PALING PENTING ------------------
                        Yaitu Partisi Disk jika kalian menggunakan windows atau yang lain jangan sampai salah pilih
                        biasanya internal itu /dev/sda dan external akan tertulis /dev/sdb

                        >/dev/sda
                        >/dev/sdb

                        Kalian pilih yang sdb jika punya ssd atau hdd external, INGAT jangan sampai salah pilih
                        pilih yang ada free spacenya, dan jangan sampai salah pilih ke flashdisk karena jika kamu memilih itu
                        maka yang terjadi file untuk instalasi hilang dan instalasi gagal
                        dan juga jika kalian salah pilih disk internal maka disk itu akan TERHAPUS datanya

                        Kalian akan di suruh memilih meletakkan os ini berdampingan dengan os lain y/n:
                        karena kita pakai ssd external atau hdd maka kita pilih no

## Langkah 10. Kita akan menggunakan partisi custom,swap,data dan filesystem
                            maka kita pilih "y"

                            Setelah itu kalian akan di tanya "mulai dengan memformat partisi atau partisi kosong"
                            jawab "y"

                        -Setelah itu kalian pilih type labelnya
                            *gpt
                            *dos
                            *sgi
                            *sun
                            saya plih gpt karena sudah terbiasa dengannya jadi kita pilih gpt.

                            INGAT gpt untuk efi dan dos untuk mbr
                            dan setelah itu kita akan bikin partisi disk nya

                            =====DISK TERSEDIA 512GB====

                            /dev/sda1 - mediaboot - type = bootable atau efi = 1GB
                            /dev/sda2 - swap atau untuk swap storage dan ram = 2GB
                            /dev/sda3 - filesystem = 70GB - boleh di lebihkan jika ingin update besar karena toolsnya itu sangat banyak
                            /dev/sda4 - data = sisanya (perintah manualnya adalah "mkfs.exfat /dev/sda4")

                            Setelah itu write dan exit, anda akan mendapatkan tawaran, encrypted root kita jawab "n" karena kita mau cepat

                            dan INGAT

                            boot partition /dev/sda1 type filesystem(ext4) karena lebih stabil
                            root partition /dev/sda3 type filesystem(ext4)
                            swap partition
